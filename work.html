Featured Build

★ HACKATHON BUILD
hackrx-bajaj-MVP
Repository ↗

Intelligent policy-document Q&A, built for the Bajaj Hackathon. An end-to-end FastAPI service that takes a PDF URL and a list of questions and returns grounded answers, combining a custom visual-layout chunking method with semantic retrieval.

FastAPI OpenCV Pinecone MiniLM Embeddings Gemini TF-IDF
  • Query expansion step uses an LLM to turn each question into keyword-rich sub-queries before retrieval, improving recall on dense policy language.
  • Custom OpenCV-based chunking detects text bounding boxes on low-contrast page renders, keeping spatially-related policy text together instead of splitting on fixed character counts.
  • Multi-step retrieval blends TF-IDF page scoring with MiniLM vector search over Pinecone before generation.
